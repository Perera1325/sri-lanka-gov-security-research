# Table 4. External verifiability of the Sri Lanka CERT web-application guideline

The guideline sets 32 requirements. This table classes each by how far an outside
researcher can check it from public evidence. It states no compliance or non-compliance for
any institution. Derived from `research/cert-web-application-guideline-mapping.md`.

| Verifiability class | Requirements | Count |
| --- | --- | --- |
| Can be informed, at least partly, by passive observation | 2, 5, 6 (client side), 10, 12 (in transit), 14 (presence), 17, 26 (if a version is disclosed) | 7 |
| Only if an official body publishes a statement | 3, 19, 28, and tender-related items | 4 |
| Requires written authorization to test | 7, 13, 15, 21, 22 | 5 |
| Not publicly verifiable (internal practice) | 1, 4, 8, 9, 11, 16, 18, 20, 23, 24, 25, 27, 29, 30, 31, 32 | 16 |
| **Total** | | **32** |

Twenty-one of the 32 (5 + 16) cannot be checked by an outside researcher without written
authorization. Requirement 5 (a `gov.lk` domain) is met by all ten institutions.
